# Application language rule

Implement application behavior in Rust.
Do not add application implementations in another language.
Do not add handwritten C or C++ source or inline C or C++ payloads.
Rust declarations that bind external library APIs are permitted.
Do not move application behavior into a dependency wrapper to bypass this rule.

Preserve original names and evidence-backed behavior. Do not add success stubs.
Follow the repository instructions for claims, comms, validation and review.
Run the application language check before publication.
