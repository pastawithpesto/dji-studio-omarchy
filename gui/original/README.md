# Original DJI QML resource bundle

`original.qrc` preserves the 1,826 unique aliases in the reviewed union of the three original encrypted QML packs and original executable compiled resources, including `qrc:/qml/Main.qml`. The union has 368 unique pack aliases (364 QML files, two pack `qmldir` files, shader `/qml/AiRoughCut/shaders/shimmer.frag.qsb`, and zero-byte `/qml/pc-editor.pem`) and 1,458 unique original compiled-resource aliases. These compiled-resource payloads were decoded from resource arrays in the pinned executable into loose source files; they were not loose files in the executable. The bundle has 410 unique `.qml` aliases, including all 44 `/UIComponent/UIControls/*.qml` aliases and `/app_qrc/ColorsConfig.qml` plus `/app_qrc/RadiusConfig.qml`. It also preserves 1,180 SVGs, 222 PNGs, other image/icon assets, and the original shader payload.

This bundle is for a **separate original-shell executable target**. Define that executable, include `OriginalResources.cmake`, call `dji_studio_declare_original_shell_target(<target>)`, then call `dji_studio_attach_original_resources(<target>)`. The helper sets target properties `DJI_STUDIO_ORIGINAL_QML_IMPORT_PATH` (`qrc:/`) and `DJI_STUDIO_ORIGINAL_MAIN_QML_URL` (`qrc:/qml/Main.qml`); query them with `get_target_property` when assembling that shell. The include-scope variables with the same names are convenience values. `qrc:/` keeps the original module aliases rooted at `/Controls` and `/Config`, regardless of the directory that later calls the attach function.

The helper requires an explicitly declared executable shell, rejects any direct `.qrc` already in that target's source list, and rejects repeated declaration or attachment. The existing GUI qrc has 1,458 aliases in common with this expanded original bundle; these are the original compiled-resource aliases whose payload bytes match the pinned executable. The 211 `/app_qrc/` aliases are a separate subset count, not the full collision count. Rejecting direct qrc sources prevents direct alias collisions in the current GUI target. CMake cannot inspect resources contributed through linked libraries, generated collections, or runtime registration here; keep those out of the original shell or audit their aliases before linking. No collision-free claim is made for indirect resources. Do not attach this bundle to the existing GUI target.

`source-provenance.json` pins each file to its source artifact, source hash, byte length, original qrc alias, and RCC record where applicable. Original payload bytes are not rewritten.

The exact original `/app_qrc/i18n_data.json` JSON catalog is included with its original alias and bytes. A reviewed static source inventory reports 1,980 keys and 16 exact locale-key spellings, including both `zh-Hant` and `zh_Hant`. This does not establish native lookup/fallback behavior or the displayed locale strings. No `.qm`/`.ts` catalog was found.

This is a resource-preservation bundle, not a runnable original UI. Exact aliases and payload bytes do not establish that the original QML import graph closes, that original native QML modules/context objects/singletons are registered, or that the startup/show path succeeds. The main UI adapter/dependency closure remains unknown. Compiling the qrc is not evidence that `Main.qml` instantiates, works, or matches the Windows UI.
