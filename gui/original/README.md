# Original DJI QML resource bundle

`original.qrc` preserves exact resource aliases for the pinned original QML modules, including `qrc:/qml/Main.qml`, and the 211 `/app_qrc/...` resources from the reviewed original asset manifest. Those 211 payloads were extracted from the pinned executable's compiled resource arrays into loose source files; they were not loose files in the original executable. The bundle contains 364 unique QML files, the original `Config` and `Controls` `qmldir` files, and 211 app resources.

This bundle is for a **separate original-shell executable target**. Include `OriginalResources.cmake` after defining that executable, call `dji_studio_declare_original_shell_target(<target>)`, then call `dji_studio_attach_original_resources(<target>)`. Add `DJI_STUDIO_ORIGINAL_QML_IMPORT_PATH` to that shell's QML engine import paths. The import path is `qrc:/`, so the original module aliases stay rooted at `/Controls` and `/Config`.

The helper rejects a target with a direct `.qrc` source, requires declaration as a separate executable, and rejects repeated declaration or attachment. This prevents direct double-attachment with the unchanged GUI manifest, which has 211 aliases in common with this bundle (the reviewed aliases are byte-identical). The helper cannot inspect resources contributed through linked libraries, generated resource collections, or runtime registration. An integrator must keep those out of the separate shell or audit their aliases before linking; no collision-free claim is made for unknown linked resources. Do not attach this bundle to the existing GUI target.

`source-provenance.json` pins each file to its source artifact, source hash, byte length, original qrc alias, and RCC record where applicable. Original payload bytes are not rewritten.

The exact original `/app_qrc/i18n_data.json` JSON catalog is included with its original alias and bytes. A reviewed static source inventory reports 1,980 keys and 16 exact locale-key spellings, including both `zh-Hant` and `zh_Hant`. This does not establish native lookup/fallback behavior or the displayed locale strings. No `.qm`/`.ts` catalog was found.

This resource-only bundle does not close original UI startup or import dependencies. The broader reviewed compiled-alias inventory contains 44 additional `/UIComponent/UIControls/*.qml` aliases absent from this bundle, plus the `/icons` tree required by original QML sources. `/app_qrc/ColorsConfig.qml` and `/app_qrc/RadiusConfig.qml` are present here under their exact app aliases; they do not supply the missing `/UIComponent` tree. The bundle also does not supply the original executable's native QML modules, context objects, singleton registrations, or startup/show path. The main UI adapter/dependency closure is unknown. Compiling the qrc is not evidence that `Main.qml` instantiates, works, or matches the Windows UI.
