## Resource attachment contract

`gui/original/OriginalResources.cmake` is a self-contained include fragment for a separate original-shell executable. The consumer defines its shell target, includes the fragment, calls `dji_studio_declare_original_shell_target(target)`, then `dji_studio_attach_original_resources(target)`. The declaration records target properties for `qrc:/` and `qrc:/qml/Main.qml`; attachment obtains `original.qrc` using `CMAKE_CURRENT_FUNCTION_LIST_DIR`, which remains tied to the helper’s definition directory if inclusion/attachment happen from a child directory. The helper rejects missing targets, non-executable targets, undeclared attachment, direct existing `.qrc` sources, repeated declaration and repeated attachment. The existing GUI qrc collision count is 1,458 direct aliases. The helper cannot enumerate resources contributed indirectly by linked libraries, generated qrcs or runtime registration; no broad collision-free claim is made.

The README states the exact alias/QML/image coverage and clearly says this is a resource-preservation bundle, not a runnable original UI. Original native QML module registration, context objects/controllers, complete import closure and main-shell startup/show path remain unknown. Localization JSON bytes are included as an original compiled resource; prior reviewed catalog inventory records 1,980 keys and 16 exact locale spellings, but lookup/fallback/display behavior is not established here.
