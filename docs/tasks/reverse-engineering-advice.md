# Reusable reverse engineering advice

Record proven techniques from comms in a shared advice document.
Limit each technique to three sentences in ASD-STE100 technical English.
Exclude file names, addresses, task assignments, and file-specific instructions.

## Scope

- Add `docs/reverse engineering advice.md`.
- Link it from the comms section in `AGENTS.md`.
- Keep supporting evidence in the PR and comms.

## Completion check

Check each technique against saved successful results or reviewed corrections.
Check sentence counts, links, file scope, and current main.
Obtain separate source review and milestone verification.
